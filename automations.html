How the score works

The bar estimates how broadly an automation improves the work—from one targeted task to a team-critical operating system. It measures practical reach, not code quality.

  1. 1/5
    Targeted utility

    Solves one focused task for an individual user.

  2. 2/5
    Focused improvement

    Saves meaningful time within a defined process.

  3. 3/5
    Recurring workflow

    Improves work that teams repeat regularly.

  4. 4/5
    Multi-step operation

    Connects several tasks, systems, or handoffs.

  5. 5/5
    Team-scale impact

    Supports business-critical work across a team.
